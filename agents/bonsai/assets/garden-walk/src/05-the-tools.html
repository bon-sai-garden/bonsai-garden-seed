Fifth, the tools

Now your own hand.

To plant a garden, a few tools have to live on your machine. I'll show each step, and you run it.

I read along. I never type for you. Nothing on this page asks for a password or a key, and nothing here ever will.

Not ready yet. This step waits on an installer that isn't finished. Until it is, a walk ends at the turn, and I say so. This page shows how it will go.

Before the first command

Five free programs have to be on your machine first. I ask each for its version, which reads and changes nothing, and I show you the five answers. If one is missing, I show you where to get it, and we wait: nothing else runs until all five answer.

  • Node.js checks that what you install is genuine.
  • Python draws my introduction card.
  • Git fetches the garden's tools and keeps your garden's history.
  • uv installs and runs the garden's service.
  • Claude Code on the command line, the command called claude, which the garden needs even when you use the desktop app.

How I hand you a line

A terminal does exactly what a line says, so I keep each line short and plain.

  • One line at a time, onto an empty prompt. If a line goes wrong or hangs, press Ctrl+C first, and I wait until the prompt is empty. I never add a fix onto a broken line.
  • Anything with Japanese characters, or with several commands, comes as a small file. I write the file into your walk folder, say what it does before you run it, and you run it with one plain line.
  • After a change to your shell or your tools, a new Terminal tab. An old tab can still be running what ran before. We check the new tab before we go on.
  • Every pair of characters I offer you has been checked by the garden's own check first, never by my eye.
  • If I read your Terminal to see what went wrong, I say so, and I keep nothing of what I saw.
