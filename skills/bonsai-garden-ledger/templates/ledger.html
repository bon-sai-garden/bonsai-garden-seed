How these numbers are made, and how far to trust them

Tokens are exact. Every session keeps its own record of each model call's usage; this skill's fetch stage adds them up, each call counted once, deduplicated by message and request id — a resumed or re-synced session re-writing earlier lines does not double the total.

Newly worked (fresh) means input plus cache writes plus output: the work that was newly computed. Cache reads are kept apart, because re-reading already-cached context costs far less per token, and are never folded into fresh.

List price is null unless a price table was supplied to the fetch stage — no model name or rate is built into this skill. Cache writes are costed at 1.25× the input rate and cache reads at 0.1×, Anthropic's own published cache-pricing multipliers.

Footprint and distance are null unless a CO₂/km-per-fresh-token factor was supplied, applied to fresh tokens only. The factor itself is the caller's own reasoned figure, not something this skill asserts.

Read this before repeating any number hereTokens are exact. List price, footprint and distance are only as good as the table and factors a caller chose to supply — treat them as estimates, never a bill.
